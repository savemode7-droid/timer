# 作業タイマー 

## 概要

作業タイマーは、日々の作業時間を簡単に記録し、CSV形式で出力できる業務向けタイマーアプリです。

実際の業務での利用を前提としており、操作のしやすさ、入力ミスの防止、データ管理のしやすさを重視して開発しています。

---

# 主な機能

* 作業タイマー開始・終了
* 作業内容の記録
* 定型作業の登録
* 手入力メモ
* 作業時間の自動計算
* 日別記録表示
* 月別集計
* CSVエクスポート
* Device ID・Record ID管理
* UpdatedAt管理
* 旧データの自動コンバート

---

# 動作環境

* Windows
* Google Chrome（推奨）
* Microsoft Edge

---

# データ保存

現在はブラウザ内にデータを保存します。

今後は以下の機能を追加予定です。

* JSONエクスポート
* JSONインポート
* Google Driveバックアップ

---

# 開発方針

このアプリは、実際の業務で毎日使用することを目的として開発しています。

開発方針

* シンプルで迷わない操作
* 入力ミスを防ぐUI
* データの互換性を維持
* バージョンアップ時も過去データを利用可能にする
* 実際の利用者（Satoshiさん・奥様）の要望を最優先に改善する
